
# Цифровий підпис зображень за допомогою RSA

## Огляд застосування
Ця система призначена для створення цифрового підпису зображень та їх перевірки, це забезпечує автентичність зображення. Підпис зберігається в метаданих PNG зображення, що дозволяє легко перевірити оригінальність файлу без зміни самого зображення.

Підписування здійснюється за допомогою RSA-алгоритму, де приватний ключ використовується для підпису, а публічний — для перевірки підпису. Зображення з підписом можна перевірити на коректність за допомогою публічного ключа.

## Опис підходу

1. **Генерація RSA ключів**:
   - Програма генерує пару RSA ключів (приватний та публічний).
   - Приватний ключ використовується для створення цифрового підпису, а публічний — для його перевірки.
   - Ключі зберігаються в папці `keys/` під іменами `private_key.pem` та `public_key.pem`.

2. **Підписування зображень**:
   - Зображення підписується за допомогою приватного ключа.
   - Хеш зображення (на основі пікселів) підписується і вбудовується в метадані PNG зображення як "signature".
   - Зображення з підписом зберігається у папці `images/` як `signed.png`.

3. **Приховування підпису**:
   - Підпис приховується в метаданих PNG зображення, що забезпечує його непомітність.
   - Підпис може бути витягнутий тільки за допомогою публічного ключа.

4. **Перевірка підпису**:
   - Для перевірки підпису потрібно витягти його з метаданих зображення і порівняти з хешем зображення, що обчислюється публічним ключем.
   - Перевірка підпису здійснюється за допомогою функції `verify.py`, де перевіряється автентичність зображення.

## Використання

### Підготовка:
1. Завантажте зображення у папку `images/` під іменем `original.png`.
2. Встановіть необхідні бібліотеки:
   ```
   pip install -r requirements.txt
   ```

### Кроки:

#### Варіант 1: Автоматичний запуск через `setup_all.py`
Для одночасного запуску всіх етапів (генерація ключів, підписування зображення та перевірка підпису) запустіть:
```
python setup_all.py
```

#### Варіант 2: Окремий запуск для кожного етапу
1. Для генерації ключів та підписування зображення запустіть:
```
python main.py
```
2. Для перевірки підпису зображення запустіть:
```
python verify.py
```

## Структура проєкту
- `main.py` — генерує ключі, підписує зображення та вбудовує підпис в зображення.
- `verify.py` — витягує підпис і перевіряє його коректність.
- `setup_all.py` — автоматизує генерацію ключів, підписування зображення та перевірку.
- `keys/` — містить публічний та приватний ключі.
- `images/` — містить оригінальне та підписане зображення.
- `requirements.txt` — список необхідних бібліотек.

## Важливі моменти
- Підпис можна перевірити тільки за допомогою публічного ключа.
- Зображення після підпису залишається доступним для перегляду, а підпис не змінює візуальну частину.
